Installation

// Import the ES6 module
import { FaceLookerViewer } from './FaceLookerViewer.js';

Basic Usage

const viewer = new FaceLookerViewer({
  faces: './faces/01/',
  width: 360,
  height: 360,
  cornerRadius: 8
});

document.getElementById('container')
  .appendChild(viewer.getElement());

Configuration Options

faces string - Path to face images folder
width number - Container width in pixels (default: 360)
height number - Container height in pixels (default: 360)
cornerRadius number - Border radius in pixels (default: 8)
downloadImagesAutomatically boolean - Cache images as blobs (default: false)
showDebug boolean - Show debug overlay (default: false)
enableProgress boolean - Show loading progress (default: true)
showLabel boolean - Show person name label (default: false)
draggable boolean - Make viewer draggable (default: false)
resizable boolean - Make viewer resizable (default: false)

Callbacks

const viewer = new FaceLookerViewer({
  faces: './faces/01/',
  onLoad: (imageCache, metaData) => {
    console.log('Loaded:', imageCache.size);
    console.log('Meta:', metaData.name);
  },
  onProgress: (progress, loaded, total) => {
    console.log(`Loading: ${Math.round(progress)}%`);
  },
  onReady: () => {
    console.log('Face viewer ready!');
  }
});

What is Face Looker Viewer?

A modern ES6 module that creates interactive face tracking experiences. The face follows your cursor movement by seamlessly switching between pre-rendered images from a grid system.

Built with vanilla JavaScript - no frameworks required. Perfect for interactive web experiences, portfolios, or creative projects.

How It Works

The system uses a grid-based approach with 121 pre-rendered face images covering different gaze directions (-15° to +15° on both X and Y axes with 3° steps).

As you move your cursor, the module calculates the appropriate position and instantly displays the corresponding image, creating a smooth face-following effect.
