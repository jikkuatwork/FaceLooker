Overview
Interactive face tracking module using pre-rendered image grids. Built with vanilla ES6 JavaScript - no frameworks required.
How It Works
Uses 121 pre-rendered face images (-15° to +15°, 3° steps) to create smooth gaze-following effects based on cursor position.
